12. Technical Architecture
Nospecific framework or cloud provider is confirmed in the source material. The architecture below is therefore a
recommended structure, not a claim that a particular technology has already been selected.

Frontend and mapengine
The client experience owns rendering, gestures, navigation, selection state and responsive behavior. The map engine

Store users, maps, nodes, relationships, permissions, share links, source references, messages, moderation events

AI anduniversal ingestion layer
The long-term architecture requested in the source is: source → ingestion layer → AI understanding engine →

OneofCDN'smostinnovative and commercially valuable features is Universal Link-to-Mind-Map — a

the accessible content, extract structured information, and generate an interactive mind map.
Core Concept
The workflowis: Paste Link → Detect Source → Retrieve AuthorizedContent → AI Analyze→ Extract
Information → Generate Nodes →ConnectRelationships → Create Searchable MindMap.
Supported Link Types
The systemis designed to support a widerange of link sources, including public websites, news articles,
blog posts, company pages, product pages, YouTube videos, social media profiles and posts (through
authorized APIs or user-provided data exports), PDF documents, Google Drive and Dropbox files (when
the user grants access), Wikipedia pages, and CDN's own internal links.
HowItWorks
WhenauserpastesaURL,CDN'sURLclassifieridentifies the source type and determines the
appropriate retrieval method. The system then extracts permitted text, titles, metadata, headings, dates,
people, companies, places, images, links, and categories. This raw content is processed by CDN's AI
understanding layer, which identifies entities, topics, relationships, hierarchy, relevance, and duplicates.
The graphgenerator thenconverts the AI output into CDN nodes and edges, eachtagged withsource
URLsandconfidencescores.
Semantic Search
Oncecontent has beenconverted into a network, users can asknatural-language questions about it. For
example: "Show meeverything related to manufacturing," "Find all people mentioned," "Create a
timeline from this information," or "What are the five most important topics on this website?" The AI
highlights relevant nodes and reorganizes the map around the user's query.
Multiple Links and Entity Merging
Users canpaste multiple links into the same network. If the same person, company, product, or concept
appears in several sources, CDN's AI recognizes the overlap and merges related nodes rather than
creating duplicates. This enables comprehensive research projects that aggregate information from
dozens of sources into one connected map.

Security, Privacy, and Responsible Technology
As aplatform that handles sensitive business data, personal information, financial transactions, and AI

requirements.
Identity Verification
CDNintegrates Persona — atrusted identity-verification partner — into its onboarding and security

accounts, and unauthorized access.
Permission Systems
CDN's permission architecture operates at multiple levels: workspace, map, branch, and individual node.
Users canset granular controls determining who canview, comment, edit, administer, or execute AI
agents within any part of the network. Private information never becomes visible merely because it is
connected to a sharedor public node.
Content Moderation and Anti-Abuse
Public communities and marketplaces require active moderation. CDN implements automated content
filtering, user reporting, moderation queues, and appeals processes. The platform enforces lawful-use
restrictions and deploys technical safeguards to prevent the platform from being used for illicit
activities.
AI Safety
AI agents operate within strict permission boundaries. Every significant agent action is logged. Human
approval gates prevent agents from executing high-stakes actions without oversight. Agent memory is
compartmentalized — anagent workingfor oneorganization cannot access another organization's data.
Data Privacy
User data is private by default. CDN does not sell user data. Imported content (fromLink-to-Mind-Map,
LifeMap AI, or integrations) remains under the user's control. The platform provides clear data-export
capabilities so users can retrieve their information at any time.
Audit Trails
Every significant change — whether made by a human,an AI agent, oranautomation—islogged with
timestamps, attribution, and details. This creates accountability and enables administrators to review
platform activity comprehensively.
